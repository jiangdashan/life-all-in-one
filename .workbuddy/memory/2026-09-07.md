## v36g（13:50）：11607 写入失败真因修复——userId 裸字符串
- 用户体检报错：addRecord 业务错误 code=11607 "cannot unmarshal string into Go struct field AddRecordReq.properties of type database.PropertyValue"。27 条本机记录全部写入失败。

- 修复：①dbAdd `finalProps.userId={text:uid}`；②retagCloudToCurrentUser `properties:{userId:{text:uid}}`（此前迁移功能也因此从未生效）。
