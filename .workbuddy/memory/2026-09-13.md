## v39 四项修复（23:15-23:50）

用户诉求：
1. 习惯健康热力图天数要记实际天数，当日没操作的习惯显示为 0 天；
2. 本月的经期记录没有在周期历史中回显；
3. 心情轨迹要按时间倒序（最新最上）；
4. 库存总览增加点击类型筛选功能。

根因与修复：
- **①习惯连续天数**：`habitStreak` 游标从今天起算，今天未打卡立刻 return 0。改为 `if(!habitDone(habit,today)) cursor.setDate(-1)` → 从昨天回溯，昨天也没打卡才归零。热力图行的 `.streak-badge` 随之显示真实天数。
- **②周期历史不含当前周期**：`_pastCyc` 只收 `cyc.closed`（endDate<today），本月进行中的经期就被排除。改为收集全部 `cyclesExpanded`（仅剔除 startDate>isoDate() 的未来记录），并为 `!closed` 的行加 `.ongoing` 类 + `.hist-ongoing-tag`「进行中」徽标、文案改「已记录 N 天」。**统计口径完全不动**：`periodLens` 仍要求 `endDate<today`，进行中周期不入均值样本（避免重演 v31「一条记录就显示 1 天平均经期」）。
- **③心情倒序**：`sortedRecords` 默认已是「日期倒序 + 同日 createdAt 倒序」，`renderMoodTimeline` 里多余的 `.slice().reverse()` 把顺序又翻回升序 → 去掉即可。
- **④库存总览筛选**：原本 `#storageOvCats` 有点击监听，但 `renderStorageOverview` 始终用全量 records 渲染，点了只有下方清单变、面板本身毫无变化 → 用户以为没生效。改为：分类**卡片**始终按全量统计（便于随时切换），**条形图/提醒/明细**只渲染当前 `storageFilter` 命中的 `view`；新增 `#storageOvFilterNote` 提示条（「只看「食品」· N 种 / M 件」+「显示全部」按钮 `data-action="storage-filter-clear"`）；两个筛选容器（chips 与总览卡）合并为同一个 `_storageFilterClick`，支持**再点一次恢复全部**。CSS 加 `.storage-ov-filternote`（`:empty{display:none}`）与 `.period-history-row.ongoing`/`.hist-ongoing-tag`。

坑与注意：
- **`renderStorageOverview` 会 innerHTML 重建分类卡** → 冒烟测试里保存的 card 引用会失效（再 dispatch click 无效），每次点击前必须重新 querySelector。
- v31 旧测试用硬编码日期 `2026-09-06` 当"今天"（实际已 09-13），基线就已有 4 项失败（日期漂移）；本次改动又使 3 条编码"当前周期不进历史"的断言失效 → 已按 v39 新需求改为断言「回显且带进行中徽标」。判定新影响务必**用改动前备份跑基线对比**。
