# 生活全能工作台（日常集）

一个单文件、零依赖的个人数字生活工作台，覆盖记账、习惯打卡、减脂健身、日程待办、心情记录、睡眠、经期、学习、回本物品、收纳、书影音、倒数日等 14 个日常模块。

在线地址：https://workbuddy.link/p/IAP7cP1ljx7juu0hAdPdVy

## 特性

- **单文件 HTML**：全部 CSS / JS / 图标内联，无任何外部 CDN、框架、字体依赖，离线可用
- **多设备双向同步**：基于 WorkBuddy 资料库数据表能力，数据在线存储、多端自动同步
- **本地离线兜底**：断网时自动降级为 localStorage，恢复后自动补传
- **数据安全**：每日快照备份（本机 + 云端分片）、误清空可恢复、多用户空间隔离
- **PC / 移动端双适配**：移动端可添加到桌面当 App 使用

## 本地运行

直接双击 `life-all-in-one.html` 用浏览器打开即可。数据默认存 localStorage，联网时自动同步到云端。

> 注：本地直接打开时无云端桥接，同步/备份功能会降级为仅本机存储；完整功能请通过上方在线地址访问。

## 技术栈

- 原生 HTML / CSS / JavaScript（无构建步骤）
- 数据存储：WorkBuddy 资料库数据表（云端）+ localStorage（本地兜底）
- 图标/图表：内联 SVG
